# ONYX-NULL Code of Conduct

## Purpose

ONYX-NULL exists to encourage open technical research, experimentation, documentation, and collaboration.

Participants are expected to contribute in a professional and constructive manner.

## Expected Behavior

Participants should:

* treat others with respect
* critique ideas rather than people
* provide technical evidence when making security claims
* document assumptions and limitations
* welcome corrections
* acknowledge uncertainty
* give appropriate credit
* avoid intentionally misleading security or privacy claims

## Unacceptable Behavior

The following behavior is not acceptable:

* harassment
* discrimination
* threats
* deliberate misinformation
* impersonation
* doxxing
* publishing private information without permission
* knowingly making false security claims
* intentionally hiding relevant vulnerabilities or dependencies

## Technical Disagreement

Technical disagreement is expected.

Participants should prioritize:

* reproducible evidence
* measurements
* primary documentation
* source code
* schematics
* test results
* clearly defined threat models

Disagreement should remain focused on the technical issue.

## Enforcement

Project maintainers may remove content or restrict participation when behavior repeatedly violates this code of conduct.

## Philosophy

ONYX-NULL values transparency, curiosity, technical rigor, and the willingness to admit when something does not work.
