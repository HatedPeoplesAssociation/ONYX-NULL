## Versioning

ONYX-NULL uses different identifiers for project releases and hardware revisions.

Examples:

```text
ONYX-NULL v0.1.0
ONX-P0
ONX-P1
ONX-M1-REV-A
ONX-M1-REV-B
```

Prototype identifiers should not be interpreted as production releases.
