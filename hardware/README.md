# ONYX-NULL Hardware

This directory contains the electrical hardware designs, component documentation, bills of materials, prototype records, and manufacturing files for ONYX-NULL.

ONYX-NULL hardware is being developed around four primary principles:

1. owner control
2. explicit trust boundaries
3. physical isolation where practical
4. reproducibility

The hardware is currently experimental.
