# Security Policy

ONYX-NULL is currently an experimental research and development project.

## Reporting Security Issues

Please do not publicly disclose exploitable vulnerabilities through GitHub Issues, Discussions, pull requests, or public social channels.

A private vulnerability-reporting mechanism will be established before ONYX-NULL reaches a public hardware release.

Non-sensitive security architecture concerns may be discussed publicly.

## Security Philosophy

ONYX-NULL follows several principles:

* minimize unnecessary trust
* isolate potentially untrusted components
* prefer hardware-enforced controls where practical
* document proprietary dependencies
* verify rather than assume
* measure security properties whenever possible
* make limitations public

## Security Claims

ONYX-NULL does not claim to be:

* unhackable
* anonymous
* untraceable
* surveillance-proof
* immune to radio direction finding
* immune to compromised telecommunications infrastructure
* immune to physical observation
* secure against every possible adversary

Any active communications device produces some form of observable information.

Security features documented by ONYX-NULL should be treated as design objectives until implementation and testing demonstrate otherwise.

## Disclosure

Known vulnerabilities and security limitations will be documented once disclosure can be performed responsibly.

## Supported Versions

There are currently no production-supported ONYX-NULL releases.

Development prototypes are experimental and should not be used for safety-critical or emergency communications.
