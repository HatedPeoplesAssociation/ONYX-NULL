# ONYX-NULL Licensing

ONYX-NULL contains multiple types of intellectual property and may therefore use different licenses for different parts of the project.

The final licensing structure has not yet been selected.

## Planned Licensing Categories

### Hardware

A hardware-specific open-source license will be selected before public hardware release.

Potential candidates include:

* CERN Open Hardware Licence Permissive
* CERN Open Hardware Licence Weakly Reciprocal
* CERN Open Hardware Licence Strongly Reciprocal

### Software

Software components will use appropriate OSI-approved open-source licenses.

The exact license may vary by component.

### Documentation

Documentation will use an appropriate open-content license.

### Branding

The ONYX-NULL name, logos, and project identity may remain protected separately from the open hardware and software designs.

Open source does not require unrestricted use of project branding.

## Third-Party Components

Third-party components retain their original licenses.

All significant third-party dependencies should be documented.

## Proprietary Components

If ONYX-NULL requires proprietary firmware or hardware components, those dependencies will be explicitly documented.

See:

`docs/PROPRIETARY_COMPONENTS.md`

## Current Status

Do not assume any specific license applies until the relevant license files have been added to this directory.
