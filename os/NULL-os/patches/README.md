# NULL/OS Patches

This directory contains source patches maintained by NULL/OS.

---

# Principle

Upstream fixes are preferred where practical.

Long-term private patch sets create maintenance and security burden.

---

# Every Patch Should Document

```text
Name:

Upstream Project:

Upstream Version:

Purpose:

Security Impact:

Privacy Impact:

Upstream Issue:

Upstream Pull Request:

Still Required:
```

---

# Patch Naming

Example:

```text
0001-kernel-disable-unused-interface.patch

0002-network-add-default-policy.patch
```

---

# Upstreaming

Where a change is broadly useful, contribution upstream should be considered.

---

# Removal

Patches should be removed when:

- upstream implements the change
- architecture changes
- patch is obsolete
- patch creates unacceptable maintenance burden
