# ONYX-NULL Logo Assets

This directory contains official and experimental ONYX-NULL branding assets.

---

# Brand Name

```text
ONYX-NULL
```

---

# Project Descriptor

Preferred descriptor:

```text
Open Mobile Communications Platform
```

---

# Principle

Preferred project principle:

> Trust less. Verify more.

---

# Logo Goals

The visual identity should communicate:

- technical precision
- privacy
- owner control
- open hardware
- minimalism
- security
- experimentation

---

# Avoid

Avoid branding that implies unsupported claims such as:

```text
UNTRACEABLE

UNHACKABLE

ANONYMOUS

NSA-PROOF

MILITARY-GRADE
```

unless a specific technical term is being used accurately in documentation.

---

# Typography

Typography should be documented once finalized.

Use fonts that permit redistribution or provide clear installation instructions.

Do not commit restricted commercial fonts to the repository.

---

# PCB Branding

The ONYX-NULL mark may eventually appear on PCB silkscreen.

Example:

```text
ONYX-NULL
ONX-M1 REV-A
```

Silkscreen branding should not obscure:

- component references
- polarity markings
- test points
- regulatory markings

---

# Trademark

Open-source licensing of hardware or software does not automatically grant unrestricted rights to project branding.

A formal trademark policy may be developed later.
