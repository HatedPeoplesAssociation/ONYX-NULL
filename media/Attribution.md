# ONYX-NULL Media Attribution

This document records the source and licensing information for third-party media used by ONYX-NULL.

---

# Principle

Do not use third-party media without understanding its license.

---

# Attribution Template

Use the following format:

```text
Asset:

Filename:

Creator:

Source:

License:

License URL:

Modified:

Modification Description:

Required Attribution:

Notes:
```

---

# ONYX-NULL Original Media

Media created specifically for ONYX-NULL should identify the creator when practical.

Example:

```text
Asset:
ONYX-NULL Primary Logo

Creator:
ONYX-NULL Project

License:
TBD

Source:
Original work
```

---

# Manufacturer Images

Manufacturer images may be useful for research documentation.

Before redistributing them in the repository, verify whether redistribution is permitted.

Where permission is unclear, link to the manufacturer documentation instead.

---

# Datasheet Images

Diagrams copied from datasheets may be copyrighted.

Prefer:

- linking to the source
- creating original diagrams
- using only what licensing permits

---

# Third-Party Logos

Third-party trademarks and logos remain the property of their respective owners.

Their appearance in technical documentation does not imply endorsement.
