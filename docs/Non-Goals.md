# ONYX-NULL Non-Goals

ONYX-NULL is not intended to provide impossible or misleading guarantees.

## ONYX-NULL Does Not Claim To Be

* untraceable
* anonymous by default
* unhackable
* surveillance-proof
* invisible to radio receivers
* immune to physical observation
* immune to compromised infrastructure
* immune to every zero-day vulnerability

## Radio Reality

Any active radio transmitter may potentially be detected, characterized, or localized.

Hardware isolation can control whether a radio is powered.

It cannot make an active transmitter physically undetectable.

## Network Reality

Internet and telecommunications systems inherently expose some metadata to infrastructure required to route communications.

ONYX-NULL may reduce exposure but cannot eliminate every external trust relationship.

## User Behavior

ONYX-NULL cannot prevent users from voluntarily revealing identifying information through:

* accounts
* messages
* websites
* social media
* location sharing
* application permissions
* behavioral patterns

## Absolute Security

The project does not promise absolute security.

Security depends on:

* hardware
* software
* firmware
* configuration
* updates
* user behavior
* upstream infrastructure
* unknown vulnerabilities
