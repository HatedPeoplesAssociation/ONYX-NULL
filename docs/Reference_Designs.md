# ONYX-NULL Reference Designs

## Purpose

ONYX-NULL should learn from existing systems rather than reinvent every design decision.

## Projects to Study

### GrapheneOS

Research:

* application sandbox
* hardened allocator
* verified boot
* radio isolation
* hardware-backed keys
* update model
* Pixel hardware security

### CalyxOS

Research:

* privacy model
* microG
* firewall architecture
* boot security
* usability tradeoffs

### PinePhone

Research:

* schematics
* hardware kill switches
* modem architecture
* power system
* audio design
* repairability

### PinePhone Pro

Research:

* hardware architecture
* compute platform
* Linux support
* modem isolation

### Librem 5

Research:

* hardware kill switches
* modem isolation
* Wi-Fi isolation
* Linux mobile architecture

### AOSP

Research:

* application sandbox
* permissions
* SELinux
* Verified Boot
* hardware abstraction
* update model

## Comparison Criteria

For every platform record:

* boot security
* update security
* kernel support
* modem isolation
* Wi-Fi architecture
* proprietary firmware
* hardware switches
* secure element
* application sandboxing
* power consumption
* repairability
* documentation quality

## Goal

The purpose of this research is not to declare a winner.

The goal is to identify useful architectural ideas and known failure modes.
