# ONYX-NULL P0 Requirements

## Purpose

P0 is the first functional ONYX-NULL bench prototype.

P0 is not intended to resemble a finished smartphone.

## Required Capabilities

P0 must:

* boot an open-source operating system
* provide a usable display
* accept microphone input
* output audio
* connect through Wi-Fi
* support a VPN
* support SIP/VoIP
* establish encrypted Internet communications
* successfully place an outgoing telephone call

## Optional Capabilities

P0 may include:

* touchscreen
* hardware privacy switches
* external keyboard
* external headset

## Not Required

P0 does not require:

* battery operation
* cellular modem
* cameras
* custom PCB
* custom enclosure
* pocket-sized design
* custom operating system
* production-grade security

## Success Condition

P0 is considered successful when:

> ONYX-NULL P0 successfully places its first telephone call.

The event should be documented with:

* date
* hardware configuration
* software configuration
* photographs
* test notes
