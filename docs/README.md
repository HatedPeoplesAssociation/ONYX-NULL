# ONYX-NULL Documentation

This directory contains the technical, security, privacy, architecture, and research documentation for ONYX-NULL.

## Core Documents

### `THREAT_MODEL.md`

Defines:

* assets
* adversaries
* attack surfaces
* assumptions
* protected scenarios
* excluded scenarios

### `TRUST_MODEL.md`

Documents which components must be trusted and which components are treated as potentially hostile.

### `SECURITY_GOALS.md`

Defines the security properties ONYX-NULL attempts to achieve.

### `NON_GOALS.md`

Explicitly documents problems ONYX-NULL does not claim to solve.

### `REQUIREMENTS-P0.md`

Defines the requirements for the first working prototype.

### `ARCHITECTURE.md`

Documents the evolving hardware and software architecture.

### `NETWORK_THREAT_MODEL.md`

Documents network-visible metadata and communication trust boundaries.

### `REFERENCE_DESIGNS.md`

Records research into existing secure phones, open hardware platforms, and mobile operating systems.

### `PROPRIETARY_COMPONENTS.md`

Tracks closed-source firmware, hardware, drivers, and other dependencies.

### `HARDWARE_TRUST.md`

Documents hardware trust boundaries and isolation mechanisms.

### `PRIVACY.md`

Documents privacy objectives, data exposure, metadata, and limitations.

## Research

Unfinished research belongs under:

`docs/research/`

Research documents should identify:

* question
* requirements
* sources
* candidates
* findings
* security implications
* privacy implications
* conclusion
