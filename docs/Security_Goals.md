# ONYX-NULL Security Goals

## Primary Goals

ONYX-NULL aims to provide:

* owner-controlled hardware
* transparent architecture
* minimized attack surface
* encrypted storage
* secure communications
* isolated radios
* physically enforceable privacy controls
* secure boot where supported
* authenticated updates
* rollback protection where supported
* documented trust boundaries
* minimal privileged software
* reproducible software builds where practical

## Hardware Goals

The hardware should eventually support:

* independently controllable radios
* hardware microphone isolation
* hardware camera isolation
* hardware radio isolation
* debug-interface control
* secure key storage
* repairability
* replaceable components where practical

## Software Goals

The software should eventually support:

* application isolation
* least privilege
* encrypted storage
* firewall controls
* VPN support
* secure update verification
* minimal default services
* minimal telemetry
* auditable configuration

## Network Goals

Communications should prioritize:

* encryption
* authenticated endpoints
* minimal metadata
* clear provider trust boundaries
* user-controlled network routing

## Security Philosophy

Security claims should be measurable.

Where possible:

**test it, document it, reproduce it.**
